# Glossário de termos do Git

- **Git**: sistema de controle de versão distribuído.
- **pull**: busca alterações do remoto e integra à branch local.
- **push**: envia commits locais para o repositório remoto.
- **commit**: registro de um conjunto de alterações no histórico.
- **branch**: linha de desenvolvimento independente.
- **fork**: cópia de um repositório de terceiros para a própria conta.
- **clean**: remove arquivos não rastreados do diretório de trabalho.
- **clone**: cópia local completa de um repositório remoto.
- **pull request (PR)**: pedido de revisão e integração de uma branch em outra.
